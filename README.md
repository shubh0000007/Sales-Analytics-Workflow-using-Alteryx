# Sales-Analytics-Workflow-using-Alteryx

## Overview
This project demonstrates an end-to-end sales data analysis workflow built using Alteryx. The goal was to clean, transform, and integrate multiple datasets to generate meaningful business insights around sales performance, profitability, and regional trends.

---

## Datasets Used
- Customer Orders (East)
- Customer Orders (West)
- Order Details
- Regions

---

## Workflow Steps
- Data cleaning and removal of duplicates  
- Standardizing and formatting date fields  
- Joining multiple datasets for unified analysis  
- Creating calculated fields such as Profit, Cost, and Profitability  
- Aggregating data for reporting and analysis  

---

## Key Insights
- Identified top 25 most profitable orders  
- Analyzed most profitable days of the week  
- Performed category and sub-category level profit analysis  
- Compared regional order volumes and performance trends  

---

## Tools Used
- Alteryx Designer
