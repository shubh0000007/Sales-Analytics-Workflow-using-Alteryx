# Sales-Analytics-Workflow-using-Alteryx

Sales Analytics Workflow using Alteryx
Overview

This project focuses on building an end-to-end data analytics workflow using Alteryx by integrating multiple datasets and generating business insights.

Datasets Used
Customer Orders (East)
Customer Orders (West)
Order Details
Regions
Workflow Steps
Data cleaning and deduplication
Data transformation and joining datasets
Feature engineering (profit, cost, profitability)
Data aggregation and analysis
Key Insights
Identified top 25 orders by profit
Analyzed most profitable days of the week
Performed category-level profit analysis
Compared regional order distribution
Tools Used
Alteryx Designer
